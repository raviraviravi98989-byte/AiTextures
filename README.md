# AI Textures

A Minecraft Fabric mod that generates textures using AI without requiring an API key.

## Features

- 🎨 AI-powered texture generation
- 🚀 Fabric mod for Minecraft 1.21.1
- 🔓 No API key required
- ⚡ Lightweight and efficient

## Requirements

- Java 21 or higher
- Minecraft 1.21.1
- Fabric Loader

## Installation

1. Download the latest release from [Releases](https://github.com/raviraviravi98989-byte/AiTextures/releases)
2. Place the `.jar` file in your `mods` folder
3. Launch Minecraft with Fabric

## Building from Source

### Prerequisites
- Java Development Kit (JDK) 21+
- Gradle 8.1+

### Build Steps

```bash
# Clone the repository
git clone https://github.com/raviraviravi98989-byte/AiTextures.git
cd AiTextures

# Build the mod
./gradlew build

# The compiled JAR will be in: build/libs/
```
