# Contributing to AI Textures

Thank you for your interest in contributing! Here's how you can help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/AiTextures.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Test thoroughly
6. Commit with clear messages: `git commit -m "Add feature: description"`
7. Push to your fork and submit a Pull Request

## Code Style

- Use 4 spaces for indentation
- Follow Java naming conventions
- Write clear, descriptive variable names
- Add comments for complex logic
- Keep methods focused and small

## Pull Request Process

1. Update the README.md if needed
2. Ensure your code compiles without errors: `./gradlew build`
3. Write a clear PR description explaining your changes
4. Be responsive to feedback and review comments

## Reporting Issues

- Use GitHub Issues to report bugs
- Provide detailed information about the issue
- Include steps to reproduce if applicable
- Attach error logs or screenshots when helpful

## Questions?

Feel free to open a GitHub Issue for questions or discussions!
